Every chart on the Monitor can be downloaded, and so can everything at once. This page lists each chart's files with links that stay the same from one update to the next: data/<chart>.csv, data/<chart>.es.csv and data/<chart>.json, where <chart> is the identifier under each title below (the same one in each chart's link, #ind-<chart>). The files are rewritten at each update, twice a day; the addresses do not change. If a chart is ever renamed or retired, its old address will keep working or say where it went.

What is in the files. The CSV holds the chart's series as the site shows them, one column per variant, with units in the headers. The JSON is what the page itself reads: dates, every variant, units, sources and the dates of the latest observation and the latest check. Charts built from tables (rankings, maps, statements) link the table files instead. Every series ever received is also stored with the date it was received: the revision histories let anyone rebuild a chart as it looked on a past date. How each number is computed is on the Methodology page.

Use and citation. The data come from INDEC, the BCRA, the Ministry of Economy and the other sources named on each chart, under their own terms; the Monitor's transformations are free to use with attribution. Please cite the Monitor and the original source (how to cite). For programs, catalog.json lists every chart and every stored series with its files. Errors and requests: GitHub issues.
